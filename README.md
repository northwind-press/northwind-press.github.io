# northwind-press.github.io

Jekyll site built by GitHub Pages from `main`. No JS, no theme gem.

- Articles: `_posts/YYYY-MM-DD-slug.md` — see [HANDOFF.md](HANDOFF.md) for the front matter and process.
- Layouts: `_layouts/default.html`, `_layouts/post.html`. Styles: `assets/css/style.css`.
- Local preview: `bundle install && bundle exec jekyll serve`.
- Only tech-lead merges to `main` (merging publishes). Work on branches.
